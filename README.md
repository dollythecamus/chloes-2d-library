# 2D Godot library
> by chloe

with all the good tools chloes been developing for a while ! from games:

- SOMBRE ASTRA
- Alvorada
- (unfinished game from felpojam)

basic module scripts are very good for reproducibility and scale.
the unique subtle way that these features work, makes for a well rounded game that doesn't feel like a many coded parts stuck together in any order
having these scripts ready means i can point my focus a lot more towards game design and feel

features:
- basic module scripts
	- movement, grid move and rotation
	- input controls
	- paths and follow path
	- pickable objects
	- picking entity
	- scenario areas
	- health, hit, hurt
	- tutorial hint helper
- minimal ui (font)
- dialogue
- rendering 
	- RTE text effects
	- animated frames
	- baking to a spritesheet
- abstract
	- player control
	- enemy
	- weapons
